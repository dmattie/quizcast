# The value function on screen is steeper below the reference point than above it. What does that asymmetry represent?

- [ ] Diminishing marginal utility
- [x] Loss aversion
- [ ] Probability weighting
- [ ] Risk seeking in the gain domain

> Losses loom larger than equivalent gains, by a factor of roughly two in the
> original estimates. See [Kahneman & Tversky (1979)](https://www.jstor.org/stable/1914185).
