# Which signal do midbrain dopamine neurons encode?

- [ ] Absolute reward magnitude
- [x] Reward prediction error
- [ ] Movement velocity
- [ ] Expected uncertainty

> Schultz, Dayan & Montague (1997). The firing rate tracks the *difference*
> between reward received and reward expected, not reward itself. A fully
> predicted reward produces no response at all.
